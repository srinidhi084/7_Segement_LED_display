# Arduino 7-Segment Display Counter (IoT Minor Project)

##  Project Overview
This project demonstrates an Arduino Uno program designed to interface with a 7-Segment Display. The program cycles through digits from 0 to 9 sequentially with a 1-second delay between each number.

The project is designed and simulated virtually on Wokwi.

---

##  Features
* Sequential display of digits from 0 to 9.
* Precise 1-second interval (1000ms) between digit transitions.
* Clean and modular code using a 2D array for segment encoding.
* Virtual simulation requiring no physical hardware to test.

---

## Hardware & Tools Used
* Microcontroller: Arduino Uno
* Display: 7-Segment Display
* Simulator: Wokwi Online Arduino Simulator

---
